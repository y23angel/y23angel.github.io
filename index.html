About

A designer engineers like to work with

I care about interfaces that are calm, clear and honest about what they show. On First Fruits that meant labelling a quiet church "may be time to reach out — not a health score", and never showing "everyone is up to date" when the data simply failed to load.

Before design, I worked with networks, security and embedded boards. That background lets me read an API contract, follow a database access rule, and turn feedback from a code review into a fix the same day.
