# Olivia Yun — portfolio

A hand-coded portfolio site (HTML, CSS, JavaScript). No build step.

## Files

```
index.html          Home: hero, projects, about, skills, contact
first-fruits.html   HACKVAN2026 case study
assets/styles.css   Design tokens and styles (light and dark)
assets/main.js      Mobile menu, footer year, scroll reveal
```

## Preview locally

Open `index.html` in a browser, or run a small server:

```bash
cd C:\MyProject\portfolio
python -m http.server 8000
# open http://localhost:8000
```

## Before publishing

Search for `TODO(Olivia)` and fill in:

- Add your public email and LinkedIn to the Contact section
- Check the quick facts (GPA, languages, location)

## Publish with GitHub Pages

1. Create a repository named `y23angel.github.io`.
2. Put these files at its root and push.
3. The site appears at `https://y23angel.github.io`.

Or import the folder into Vercel or Netlify as a static site.
